# 장기+ (korean-Chess-Plus)

브라우저에서 바로 즐기는 한국 장기 게임입니다. 설치가 필요 없고, `index.html`을 열면 바로 실행됩니다.

## 기능

- **대전 방식**: 한 화면 2인 대전 / AI 대전 (쉬움·보통·어려움)
- **진영 선택**: AI 대전에서 초(선수)나 한(후수) 중 하나를 고를 수 있고, 한을 고르면 판이 자동으로 돌아갑니다
- **마·상 차림**: 마상마상, 상마상마, 마상상마, 상마마상
- **전체 규칙**: 궁성 대각선 이동, 포 넘기, 마·상 멱, 장군·외통수, 빅장, 한수쉼
- **편의 기능**: 이동할 수 있는 곳 표시, 마지막 수 표시, 무르기, 기보, 점수(덤 1.5점), 기권, 판 돌리기
- PC와 모바일 화면, 다크 모드를 지원합니다

## 📱 모바일 훈수 모드 (`advisor.html`)

핸드폰 장기 앱 화면을 노트북에서 읽어서 다음 수를 추천합니다. 어떤 장기 앱이든 첫 배치 화면에서 그 앱의 말 모양을 익히기 때문에 앱 디자인에 상관없이 쓸 수 있습니다.

1. [scrcpy](https://github.com/Genymobile/scrcpy)로 안드로이드 화면을 노트북에 띄웁니다 (USB 디버깅 필요)
2. 훈수 모드에서 **화면 연결** → scrcpy 창 선택 (PC 크롬·엣지)
3. 장기 앱에서 새 대국을 시작하면 **자동으로** 장기판 위치를 찾고, 첫 배치에서 말 모양·내 진영·마상 차림을 익힙니다
4. 대국을 진행하면 말이 움직일 때마다 추천 수가 화살표로 표시됩니다

- 마·상 구분은 처음엔 글자 모양으로 추측하고, 실제로 움직이는 모양(마 1+1칸, 상 1+2칸)을 보고 틀렸으면 스스로 고칩니다
- 한 번 익힌 말 모양은 저장되어 다음에는 대국 중간에 연결해도 바로 읽습니다 (이때 차례가 반대면 **차례 바꾸기**)
- 자동 인식이 안 되면 **직접 맞추기**에서 판 꼭짓점 클릭과 차림 선택으로 할 수 있습니다

- **나란히 보기**: 핸드폰 화면 옆에 인식한 판과 추천 수
- **겹쳐 보기**: 핸드폰 화면 위에 장기+ 판을 반투명하게 덮어서 추천 수 표시
- 설정과 익힌 말 모양은 브라우저에 저장되어 다음에 다시 할 필요가 없습니다

> AI 상대 연습이나 복기용으로 사용하세요. 사람과 두는 온라인 대국에서 사용하면 부정행위로 계정이 정지될 수 있습니다.

## 실행 방법

- `index.html` 파일을 브라우저로 열면 됩니다.
- GitHub Pages로 배포할 때는 저장소의 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다.

## 규칙 메모

- 점수: 차 13, 포 7, 마 5, 상 3, 사 3, 졸·병 2. 한은 덤 1.5점을 받습니다.
- 빅장(두 궁이 사이에 아무것도 없이 마주 보는 상태)이 걸린 뒤 상대가 풀지 않으면, 그 시점의 점수가 높은 쪽이 이깁니다.
- 장군 상태가 아니면 한수쉼(차례 넘기기)을 할 수 있습니다.

## 파일 구조

```
index.html        대국 화면
advisor.html      모바일 훈수 모드
css/style.css     디자인
js/rules.js       장기 규칙 엔진 (말 이동, 장군, 빅장, 점수)
js/ai.js          AI (알파-베타 탐색)
js/board-view.js  판 그리기 (공통)
js/ui.js          대국 화면 조작
js/vision.js      화면 인식 (말 모양 익히기·읽기)
js/advisor.js     훈수 모드 조작
```
